## 7-1. 関係各位とうまく情報を共有する — 施策エントリーフォーム設計

### 施策管理シートの目的

同じビジョン（イメージや方向性）を持ってスムーズに施策を考案したり案件を進めたりして、実施する（or した）施策の効果を充分に発揮させるには「情報共有・意思疎通が欠かせない」のでシートを用意する。

### 【施策エントリーフォーム】設計項目例

| 項目名 | 内容 / 選択肢 / 設計例 |
| :--- | :--- |
| **記入日 / エントリー日 / 承認日** | 0000年00月00日 |
| **施策タイトル** | （1行のテキストボックスにて記述） |
| **起案者** | 部署名 / 氏名 |
| **施策の種類** | 集客拡大 / サイト内改善 / 機能改善 / A/Bテスト / 商品改善 / コスト削減 / その他（〜） |
| **重要度・緊急度** | <ul><li>**A:** 「致命的なエラー」や「緊急性の高い事案」が発生している場合、あるいは即時性が大切な施策</li><li>**B:** 売上インパクトが大きい・早い段階での実施が必要</li><li>**C:** 改善要望・競合優位・顧客満足度アップ etc</li><li>**D:** 実施は必須ではないが改善につながると思われる案件や施策</li></ul> |

## 7-2. 施策管理の進捗共有・KPI設計 & 現状との差分逆算アプローチ

### 施策管理シートの運用

このシートを元に各施策（実施の有無に問わず）を管理し、目標（KGI）や指標（KPI）に照らし合わせて案件の進捗を共有。関係各位での共通認識を持つ上で活用する。  
また、可能であれば定期的に関係各位（案件参加者）で自社や同業他社の事例などを発表する場を設けて改善施策の実行と効果検証（PDCA）を行い、サービスや改善に活かしていく。

### ☆案件（や施策）の進捗を共有する上で大切なこと

#### ① KPI設計

それぞれの商品 / サービスや各エリアごとで（金銭的）価値を決める。  
例: 商品やサービスは、その金額・人気具合で判断、エリアは（売上などの）数値が大きいところなど。  
**☆ゴールに関連するコンバージョン価値を決定する。**  
※リスティング広告など広告を打っている場合、「広告掲載料（コスト）」と「送客件数から想定される売上金額（リターン・成果）」も算出しておく。

#### ② 目標達成へのアプローチ / フロー及び現状の差分を知る

各商品 / サービスと各エリアでどのくらいのCV量が年間（or 月間 or 1日）で必要かを算出する。（＝①で決めた（金銭的）価値に準拠して、各商品 / サービス、各エリアにおける**目標達成に必要な数値・差分を逆算して定める・把握する**）  
例: 年間○○○万円なら各商品/サービスでXX円/月、エリアで△△円/月が必要など。  
もちろん「低・中・高単価」「低・中・高集客率」での掛け合わせなどで工夫して達成することも重要（低×中 / 中×高 / 低×高 etc…）。

#### ③ 目標達成のためにどの指標（KPI）をどのくらい改善する必要があるかを把握・理解

改善箇所の把握においても逆算して考えていく（＝モニタリングの重要性）

- **A: 年間（or 月間 or 1日）目標の達成状況を確認し、必要に応じて全体の方向性を変える判断材料に**: また現在のサイトの健康状態の把握に活用。※本当に必要な指標だけ、変化があるものだけ残して、次につながる施策/提案に努める。
- **B: 月間（or 1日）目標の達成具合や変化を察知し、必要に応じてテコ入れを行い、来月以降の施策に向けた参考とする**: ※得た気づきなどを（可能ならインフォグラフィックに加えて）毎週決まった日/時間に通知。

- **週次の通知なら:** 毎週木曜日メール（前週水〜今週火のデータを今週水に加工して木に配信）
- **日次:** 訪問者数・PV数・CV・直帰率などの動き（変化）を察知して日々配信

## 7-3. 納期・金額の見積リスク管理 & 「人月」の落とし穴

### ☆納期や金額を聞かれても即答せず「検討」の返答に留める

（例 こういうのどれくらいで出来る？？ / こんな感じのできそう？？）

#### 理由: イメージ（想定難易度）に食い違いがある場合のリスクを考えて

相手の言う「こういう〜の、こんな感じのやつ〜 …etc」という**（当初の）要望・要求は必ずエスカレートする前提で考えておくべき**。

> **例:** 最初「1＋1＝2」程度（の簡単な内容・要望）だったとしても、そもそもこちらの「1＋1＝2」と相手の「1＋1＝2」の出来度（イメージ・想定難易度）が全く異なる場合があるため。

### 人月（作業量）の落とし穴

- **1人月**: 1人が1ヶ月間作業した場合
- **3人月**: 3人が1ヶ月間作業した場合

> [!NOTE]
> **※注意点:** 人月はあくまで「おおまかな工数（作業量）把握」にのみ活用すること。人によって得意・不得意や経験年数（キャリア）も異なってくるので、**人の数だけでチームを組むのは大変危険**。

## 7-4. パラグラフ・ライティングの基本 & 相手への説明で意識すること

### パラグラフ・ライティング（The Elements of Style）

1. **① 趣旨や主張を1文に（見出し）**
2. **② 理由付け（リード）**
3. **③ 根拠の提示（本文）**

※接続詞は極力減らした方が読みやすさが向上する。

### 簡単な説明で意識すること

1. **① 枝葉（細部やこだわり）の説明をする前に**
2. **② 幹（大元の目的・目標、方向性やコンセプト）を説明することで**

聞き手は全体像を把握した上で聞けるので**相互理解の促進につながる**。  
（例: 〜の方向性のAでは〜、Bでは〜、Cでは〜）
