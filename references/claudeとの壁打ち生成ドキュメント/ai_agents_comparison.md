# AI Coding & Workspace Agents 比較ドキュメント（＋GenSpark比較）（ファクトチェック済み・2026年8月版）
本ドキュメントは、Anthropic、OpenAI、Google の3大AI企業が提供する次世代エージェントツールの位置づけ、機能的な特徴、および料金体系を網羅的にまとめたものです。加えて、自社モデルを持たず複数ベンダーのモデル・ツールを束ねる水平統合型のGenSparkについても、位置づけとデータ学習・オプトアウト事情を比較しています。

> [!NOTE]
> 本ドキュメントは元々 Gemini がまとめたものを、Claude（Sonnet 5）が公開情報にもとづきファクトチェック・修正しています。価格や仕様は変更が早い分野のため、契約前に各社公式サイト （ claude.com/pricing、openai.com/chatgpt/pricing、antigravity.google ） で最新情報を確認してください。

## 1. 各社ツールの構造と対応関係
AI各社は、「全ビジネスパーソン向けの統合エージェント（GUI画面操作）」と、「開発者向けの軽量ターミナルツール（CLI黒い画面）」の2つのラインナップをそれぞれ展開しています。

| AI提供元 | 統合組織向けエージェント（GUI／多機能） | ターミナル専用の軽量版（CLI／CUI） |
| :--- | :--- | :--- |
| **Anthropic** | **Claude Cowork** | **Claude Code** (`claude` コマンド) |
| **OpenAI** | **Codex** (Web版/App版など大元) | **Codex CLI** (`codex` コマンド) |
| **Google** | **Antigravity** (2.0 App版など大元) | **Antigravity CLI** (`agy` コマンド) |

### 整理のポイント
* **「Code」や「CLI」がつくもの**：エンジニアが黒い画面（ターミナル）でカタカタ使う、超軽量な開発特化ツール。
* **「Cowork」や「何もつかない大元の名称」**：すべての人が画面（アプリ）を通じて、PC作業（メール作成、データ抽出、フォルダ整理など）を丸ごと代行してもらう重量級の総合エージェント。

## 4. GenSpark（MainFunc Inc.）の位置づけ
上記3社（Anthropic・OpenAI・Google）はいずれも自社モデルを主軸にした「垂直統合型」だが、GenSparkは自社モデルを持たず、複数ベンダーのモデルとツールを束ねる「水平統合型」のポジションを取る点が構造的に異なる。運営会社はPalo Alto拠点のMainFunc Inc.（2023年設立）。

### 4.1 沿革
2023年にMainFunc Inc.として設立。当初はAI検索エンジンとして「Sparkpages」（根拠付き回答ページ）を提供していたが、2025年4月に「Super Agent」中心の自律エージェント型ワークスペースへ全面転換し急成長（ローンチ45日でARR$36M）。2025年11月にSeries B（$1.25B評価）を調達後、2026年3月に外部サービスへ実際にアクションを実行する「Claw」（CEOいわく「世界初のAI従業員」）を、4月にはローカルファイルを直接操作できる「Claw for Desktop」とMicrosoftとのグローバル提携（Microsoft 365へのネイティブ組み込み）を発表。2026年6月にはSeries B拡張で評価額$2.6Bに到達し、法人向け機能（ノーコードでCRM・データベース・ダッシュボード等を構築できる個別AIツール群）を拡充。直近では2026年8月に、AIネイティブなオフィススイート「GenOffice」（Word/Excel/PowerPoint/PDF互換）をオープンソース公開している。

### 4.2 技術構成（Mixture-of-Agents）
中核となる設計思想は**Mixture-of-Agents（MoA）**。単一モデルに頼るChatGPTやClaudeの通常チャットと異なり、プロンプトを受け取ると小さなサブタスクに分解し、それぞれを専門化されたAIモデル・ツールに振り分ける（あるエージェントはリサーチ、別のエージェントは画像生成、また別のエージェントはスプレッドシート構築、というように協調して最終成果物を作る）。ローンチ当初は9種類のLLM・80以上の自社ツール・10以上の厳選データセットを組み合わせる構成だったが、2026年時点のレビューでは GPT-5・Claude・Gemini を含む30以上のモデルをオーケストレーションしていると報告されている。複数のAIが互いにファクトチェックし合うことでハルシネーションを抑える設計も特徴（MoAという概念自体は2024年の学術研究に由来し、異なるモデルは異なる誤りを犯すという前提のもと、最終判定者を置くことでMMLU・BBHベンチマークで単一最良モデル比30〜40%のハルシネーション削減効果があるとされる）。

### 4.3 主な機能
* **Super Agent**：中核のオーケストレーター。プロンプトを分解しツールを選び、多段階のワークフローを実行。研究レポート、スライド、データ分析、動画、実際の電話（Call For Me）まで一プロンプトから生成。
* **AI Slides / AI Sheets / AI Sites**：編集可能なスライド（グラフ・フリー画像・ブランドカラー自動適用）、データクレンジング・数式作成・ピボットチャート対応のスプレッドシート、Webサイト自動生成。
* **AI Browser**：ライブでWebを閲覧するエージェント内蔵ブラウザ。700以上のMCPツールや外部AIモデル、多数のAPI連携を統合。
* **Call For Me**：音声対音声技術で実際に電話をかけ、予約や見積もり依頼などを代行。
* **Meeting Notes**：カレンダー連携で自動的に会議に参加し、文字起こし・要約・参加者への共有まで行う。Workspace 4.0からはSpeaklyによるリアルタイム多言語翻訳にも対応。
* **Claw（AI従業員）**：外部サービス（メール・カレンダー・GitHub・Salesforce・Slack・Teams・Notion・X等、約20アプリ）に接続し実際のアクションを実行。ユーザーごとに専用クラウドVM（独立IP・ディスク・ドメイン）が割り当てられ「privacy-by-isolation」と説明されている。常時稼働のため、PCを閉じても作業が継続する点がClaude Coworkなどデスクトップ常駐型ツールとの最大の違い。WhatsApp・Telegram・Slack・Teams経由でタスクを委任できる（ただし英語のみ対応、日本語等の非英語言語は非対応というレビューあり）。
* **ノーコード業務アプリ構築ツール群**：受信箱・ドライブ・カレンダー・既存データベース等を起点に、CRM・データベース・ダッシュボード・タスク管理などをノーコードで構築できる個別のAIツール（AI CRM ビルダー／AIデータベース作成／AIダッシュボード作成／AIタスク管理 等）として提供。※一部まとめ記事にある「AgentBase」という統合機能名は、2026年8月時点の公式サイト（製品ライン＝Genspark Claw／Speakly／GenClipboard／GenTerminal、および法人向けページ・全ツール一覧）では確認できなかった。
* **GenOffice**：2026年8月にオープンソース公開されたAIネイティブなオフィススイート（Word/Excel/PowerPoint/PDF互換）。Apache 2.0ライセンス。エンタープライズ調達判断材料というより、AI支援開発が組織の内製ツール開発サイクルを大幅短縮しうることを示す事例として注目されている。

### 4.4 他ツールとの違い
* **コーディングエージェント（Claude Code／Codex CLI／Antigravity CLI）との違い**：GenSparkの主戦場はコード編集ではなく、ドキュメント・スライド・スプレッドシート・リサーチ・電話発信など非エンジニア向けの業務成果物生成。単一の強力なモデルをエージェント的に動かすコーディング系とは異なり、複数モデル・複数ツールをオーケストレーションするMoA方式を取る。
* **Claude Cowork／Antigravity（統合エージェント）との違い**：
    * **実行場所**：Claude Coworkはローカル（デスクトップ）実行が前提でPCを閉じると停止するのに対し、GenSparkのClawはユーザー専用のクラウドコンピュータ（常時稼働の独立VM）上で動作し、PCを閉じても作業を継続する。2026年4月にはローカルファイルを直接操作できる「Claw for Desktop」も追加された。
    * **モデル構成**：自社単一モデル軸のCowork／Antigravityに対し、GenSparkは複数ベンダー（OpenAI・Anthropic・Google等）のモデルを混在させて使う。
    * **独自機能**：AI Sheets、AIブラウザ、動画・画像生成に加え、「Call For Me」による実際の電話発信はGenSpark特有。
    * **開発者向けAPI**：公開APIなし。エンドユーザー向け製品として設計されており、開発者が組み込む前提のAnthropic/Google系とは対照的。GenSparkが提供しているのはMicrosoft 365等へのネイティブプラグイン形式の統合であり、プログラム可能なAPIではない。
* **収益規模**：2026年3月時点でARR約$250M（Sacra推定）、月間アクティブユーザー200万人超、有料シート数約10万と急成長。少人数チーム（30人未満）での運営という報告もあり、開発スピードの速さと機能拡張の頻度の高さの背景になっている。

### 4.5 料金プラン
クレジット制で、タスクの重さによって消費量が変動（チャットは軽い、動画生成・長時間通話は重い）。
* **Free**：$0（クレジットカード不要）。1日100クレジット付与。主要機能を一通り試せる程度。
* **Plus**：$24.99/月（年払いで$19.99/月）。月10,000クレジット。GPT系・Claude系・Gemini系・Grok系など各社の主要モデルへのアクセスと無制限チャット・画像生成（チャット・画像生成は2026年末まで0クレジット消費）。※対応モデルの世代は頻繁に入れ替わり、2026年8月時点の公式ツール一覧では Claude Sonnet 5・Grok 4.5 等が確認できる（料金ページはログイン必須のため、Plusプランの正確なモデル一覧は要ログイン確認）。
* **Pro**：$249.99/月。月125,000クレジット（Plusの約12倍）、優先処理・ストレージ増量。
* **Team／Enterprise**：別体系。Team向け標準DPA、Enterprise向けカスタムDPA（ITAR/EAR・BAA等の業界別アドオンにも対応可）。
* ※公開APIは提供されていないため、開発者が従量課金でプログラム的に組み込むという使い方はできない。

### 4.6 データ学習・プライバシー（オプトアウト）比較
Claude・ChatGPTが単一の設定画面・単一ポリシーでオプトアウトを完結できるのに対し、GenSparkは製品（ワークスペース本体／Claw／ブラウザ）ごとにポリシーが分かれ、プラン階層によっても契約上の保証レベルが異なる。

| 項目 | Claude（Anthropic） | ChatGPT（OpenAI） | GenSpark（個人／無料〜Plusプラン） | GenSpark（Team／Enterprise） |
| :--- | :--- | :--- | :--- | :--- |
| **学習利用のデフォルト** | 消費者版はデフォルトで学習利用あり、設定でオプトアウト可 | デフォルトで学習利用あり、設定でオプトアウト可 | 情報源により記述が食い違う：2025年6月のアップデート以降「Data Training: Off」がデフォルトとする解説記事がある一方、「デフォルトで学習利用、手動オプトアウトが必要」とするセキュリティレビューも存在 | 契約（DPA）上、**自動的にオプトアウト**。GenSparkモデルの学習に一切使用しないと明記 |
| **法的な拘束力** | API利用時は商用データ処理契約で学習利用なしを担保 | ZDR（Zero Data Retention）オプションあり（有償） | 明文化された保証は限定的。第三者評価（VerifyWise）は「条件付きオプトアウト」としつつ、該当文言が現行ポリシーに実在するか自体に留保（総合評価Grade C） | DPAに基づく法的拘束力のある「Zero Training Policy」＋「Zero Data Retention」 |
| **サブプロセッサーの扱い** | － | － | OpenAI／Anthropic／Google等のサブプロセッサーも学習禁止契約＋該当時ZDRに拘束（公式説明） | 同左（Team/Enterprise向けに明記） |
| **認証・監査** | － | － | 記載限定的 | SOC 2 Type II認証、ISO 27001:2022認証取得済み |
| **透明性・一貫性** | 単一ポリシー文書で完結 | 単一ポリシー文書で完結 | ワークスペース本体・Claw・ブラウザでポリシーが分散。ブラウザ版は特にデータ処理の透明性を欠くとの指摘あり（700以上のサードパーティMCPツールを取り込む構成上、サプライチェーンリスクも懸念材料） | 相対的に明確 |
| **アカウントデータ削除** | － | － | － | 契約終了30日後に削除（Enterpriseは延長リクエスト可） |

**実務上の要点**：GenSparkを機密性の高い情報を扱う用途で使う場合、無料／個人プランの挙動を信頼せず、必ずアカウント設定（Settings → Privacy & Data等）で「AI Data Retention」トグルの現状を直接確認するか、契約ベースで保証されるTeam／Enterpriseプランを選ぶのが安全。ポリシーは2025年6月前後に一度大きく変更された形跡があり、今後も変わる可能性がある。また「Call For Me」機能は連絡先・カレンダー・会話内容へのアクセスを伴うため、この機能特有のプライバシー配慮も別途必要。
