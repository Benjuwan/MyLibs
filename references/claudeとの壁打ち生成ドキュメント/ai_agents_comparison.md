# AI Coding & Workspace Agents 比較ドキュメント（ファクトチェック済み・2026年8月版）
本ドキュメントは、Anthropic、OpenAI、Google の3大AI企業が提供する次世代エージェントツールの位置づけ、機能的な特徴、および料金体系を網羅的にまとめたものです。

> [!NOTE]
> 本ドキュメントは元々 Gemini がまとめたものを、Claude（Sonnet 5）が公開情報にもとづきファクトチェック・修正しています。価格や仕様は変更が早い分野のため、契約前に各社公式サイト （ claude.com/pricing、openai.com/chatgpt/pricing、antigravity.google ） で最新情報を確認してください。

## 1. 各社ツールの構造と対応関係
AI各社は、「全ビジネスパーソン向けの統合エージェント（GUI画面操作）」と、「開発者向けの軽量ターミナルツール（CLI黒い画面）」の2つのラインナップをそれぞれ展開しています。

| AI提供元 | 統合組織向けエージェント（GUI／多機能） | ターミナル専用の軽量版（CLI／CUI） |
| :--- | :--- | :--- |
| **Anthropic** | **Claude Cowork** | **Claude Code** (`claude` コマンド) |
| **OpenAI** | **Codex** (Web版/App版など大元) | **Codex CLI** (`codex` コマンド) |
| **Google** | **Antigravity** (2.0 App版など大元) | **Antigravity CLI** (`agy` コマンド) |

### 整理のポイント
* **「Code」や「CLI」がつくもの**：エンジニアが黒い画面（ターミナル）でカタカタ使う、超軽量な開発特化ツール。
* **「Cowork」や「何もつかない大元の名称」**：すべての人が画面（アプリ）を通じて、PC作業（メール作成、データ抽出、フォルダ整理など）を丸ごと代行してもらう重量級の総合エージェント。

## 2. 開発者向けCLIツールの比較 (3社比較)

| 比較項目 | Claude Code (Anthropic) | Codex CLI (OpenAI) | Antigravity CLI (Google) |
| :--- | :--- | :--- | :--- |
| **速度と操作感(UX)** ※各種レビュー記事に基づく主観的評価 | レビュー記事では「爆速で対話的な微調整が得意」と評されることが多い。 | レビュー記事では「実行前にしっかり計画を立ててから動く」と評されることが多い。 | 並行処理（サブエージェント・バックグラウンドタスク）と自律性のバランス型と評されることが多い。 |
| **安全性** | 許可モード／許可・拒否ルール／**OSレベルのネイティブサンドボックス**（macOSはSeatbelt、Linux/WSL2はbubblewrap）の3層構成。設定・フックによる制御に加え、ファイルシステムとネットワークをOSレベルで隔離する仕組みも搭載。 | ChatGPTのサブスク経由・APIキー経由いずれもクラウド上の隔離されたサンドボックス環境でタスクを実行。 | 標準サンドボックス＋厳格なHITL（事前承認）。権限制御やプレコマンドフックによる介入が強固。 |
| **拡張性** | **Model Context Protocol (MCP)** にネイティブ対応。サブエージェントや外部ツールの連携が強力。 | TOML形式の設定ファイル（config.toml）を使い、明確な信頼境界を引いてタスクを自動化。 | MCP対応に加え、**スキル（SKILL.md）や独自のサブエージェント定義**が容易で、プロジェクトに特化した柔軟なカスタマイズに優れる（旧Gemini CLIの機能を継承）。 |
| **コスト効率** ※目安 | 思考プロセスが長いため、大規模タスクではトークン消費量（料金）が多くなりがちという指摘がある。 | 2026年4月にメッセージ課金からトークン（クレジット）課金へ移行。従量部分が明確になった分、軽いタスクは以前より安く済むケースも。 | 無料枠は週次の計算上限（compute cap）方式。ただし2025年11月の提供開始以降、無料枠は段階的に縮小されている（1日あたりの利用可能リクエスト数が当初から大幅減）。 |

## 3. 各社の料金プラン一覧
### 月額サブスクリプション（Web/デスクトップアプリ/統合エージェント）

*   **Anthropic (Claude Cowork 等)**
    *   **無料枠**：$0 （チャットのみ、Cowork不可）
    *   **Pro プラン**：$20/月 （Claude Coworkが追加料金なしで付属。Claude Code・Claude Design等も同プランに含まれる）
    *   **Max プラン**：Max 5x が$100/月、Max 20x が$200/月 （Coworkの利用上限が大幅に拡張）

*   **OpenAI (Codex 大元 等)**
    *   **無料枠**：$0 （※修正：Codex自体はFreeプランにも限定的なトライアルアクセスとして含まれる。クレジットカード不要だが利用量はごく少ない）
    *   **Go プラン**：$8/月 （軽量利用向け。フルのクラウドタスク機能は付かない）
    *   **Plus プラン**：$20/月 （Codexエージェント機能がWeb/CLI/IDE拡張/iOSで利用可能）
    *   **Pro プラン**：Pro 5xが$100/月、Pro 20xが$200/月 （利用量の上限が5倍・20倍に拡張。「無制限」ではない）
    *   ※2026年4月よりメッセージ単位課金からトークン（クレジット）単位課金へ移行

*   **Google (Antigravity 大元 等)**
    *   **Individual (無料)**：$0 （主要モデルへのアクセスは可能だが、週次の利用上限は当初から大幅に縮小されており、現在はかなり厳しめ）
    *   **AI Pro**：2,900円/月程度 （2TBストレージ付き。利用枠リセットあり）
    *   **AI Ultra**：$100/月程度
    *   **Ultra Max**：$200/月程度 （旧$249.99から値下げ。5TB〜20TB超のストレージ、大規模な計算クォータ付属）
    *   ※AI UltraとUltra Maxは別プラン名であり、単一の「$100〜$200帯」ではない点に注意

### ターミナルツール（CLI）を利用する場合の料金体系

*   **Claude Code** [Anthropic]
    *   **サブスク一体型（またはAPI課金）**。Claude Pro（月額$20）以上の有料プランに入っていれば、追加のAPI従量課金を気にすることなく利用可能。

*   **Codex CLI** [OpenAI]
    *   **ツール自体はオープンソースで無料インストール可能**。課金対象は背後で使うモデルの利用分。
    *   利用ルートは2通り：①ChatGPTアカウントでサインインし、Free/Go/Plus/Pro等サブスクの割当分を消費する（多くのユーザーはこちら）、②APIキーで認証し、標準API料金でトークン単位の完全従量課金にする。
    *   「ツールは無料だが動かすたびに課金される」というのは②のAPIキー運用時のみに当てはまり、サブスク経由の利用がより一般的。

*   **Antigravity CLI** [Google]
    *   **無料枠あり＋サブスク連動**。週ごとの計算上限（compute cap）に達するまでは、無料アカウントでもCLIエージェントを無料で走らせることができる。ただし無料枠自体は提供開始以降に何度か縮小されている。
    *   2026年3月からはクォータ超過後に購入できるクレジット制度（1クレジット約$0.01）も導入。
    *   さらに枠を広げたい場合はAI Proプラン等に課金する。
