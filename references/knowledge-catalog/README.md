# フロントエンド & Next.js 実装ナレッジカタログ

本カタログは、過去の実装資産・学習記録から得られた実践的なノウハウやハマりどころを抽出し、**React 19 / Next.js 15+（TypeScript 5+）の現代的ベストプラクティス**に適合するよう再編・蒸留したコードリファレンス集です。

---

## 📖 カタログの構成と利用法

本カタログは「**人間が一覧して要件に合うパターンを素早く選び、AIが最小実装とアンチパターンを理解して即座に高品質コードへ具現化する**」ことを目的に設計されています。

### ファイル構成
1. **[UI操作・インタラクション編 (`ui-interactions.md`)](./ui-interactions.md)**
   - 日付連動セレクト、タイマー制御、DnD並び替え、カルーセルラッパー、アクセシビリティ（`inert`）連動、URL同期ページネーション
2. **[Next.js App Router 設計編 (`nextjs-patterns.md`)](./nextjs-patterns.md)**
   - RSC/Client境界の真実、キャッシュ＆データ取得戦略、内部APIフェッチ排除、エラー/ローディング境界設計

### 1エントリの基本フォーマット
各エントリは以下の4要素で統一されています。
- **1. 前提・設計思想**: なぜその設計が必要か、どのような場面で使うか
- **2. 最小実装コード**: 依存関係を極力削ぎ落とした、そのままAIが拡張・利用できるコード
- **3. ハマりどころ＆現代の知見**: 過去の誤解（DOM直接操作、state不整合、キャッシュ仕様の変遷など）と是正策、コードに残されていた有用な考察
- **4. AI具現化プロンプト**: AIに指示を投げる際の一発プロンプト例
